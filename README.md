VOIDLIGHT — one wisp against the shard swarm: a neon twin-stick arena survival shooter in vanilla JS + Canvas. Survive all 12 waves of geometric shards, chain kills into combo multipliers, and catch the light they drop; sound is synthesized live with WebAudio and the game runs entirely from static files with no network requests.

## Run it

```sh
node serve.ts --port 8123
# then open http://localhost:8123 in a desktop browser
```
